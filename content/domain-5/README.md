# Orchestrate multi-agent coordination

Weight: 15-20%

Whether you can coordinate multiple agents safely, isolate parallel work, capture handoffs, detect conflicts, and manage agent lifecycle changes without losing auditability.

- Apply an orchestration pattern to coordinate multiple agents (domain-5-lesson-01-apply-an-orchestration-pattern-to-coordinate-multiple-agents)
- Configure agent isolation for parallel execution (domain-5-lesson-02-configure-agent-isolation-for-parallel-execution)
- Detect and resolve agent conflicts, including overlapping code changes, duplicated effort, and contradictory outputs (domain-5-lesson-03-detect-and-resolve-agent-conflicts-including-overlapping-code-changes-duplicated)
- Configure multi-agent workflows to produce artifacts suitable for review and audit (domain-5-lesson-04-configure-multi-agent-workflows-to-produce-artifacts-suitable-for-review-and-aud)
- Document key decisions, handoffs, and outcomes across agents (domain-5-lesson-05-document-key-decisions-handoffs-and-outcomes-across-agents)
- Perform post-hoc analysis of multi-agent behavior (domain-5-lesson-06-perform-post-hoc-analysis-of-multi-agent-behavior)
- Identify failed, partial, or stalled agent executions (domain-5-lesson-07-identify-failed-partial-or-stalled-agent-executions)
- Respond to degraded behavior or coordination across agents (domain-5-lesson-08-respond-to-degraded-behavior-or-coordination-across-agents)
- Implement multi-agent recovery patterns, including rollback and human-in-the-loop (domain-5-lesson-09-implement-multi-agent-recovery-patterns-including-rollback-and-human-in-the-loop)
