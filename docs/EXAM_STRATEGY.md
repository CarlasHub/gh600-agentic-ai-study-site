# GH-600 Exam Strategy

1. Read the blueprint before studying details.
2. Treat each question as a control-plane decision: goal, context, tools, evidence, approval.
3. Prefer least privilege and reviewable GitHub artifacts.
4. Do not confuse generated output with validated output.
5. For scenario questions, identify the risk class before choosing autonomy.
6. Use mock exam review to find weak domains, then complete the matching labs.
